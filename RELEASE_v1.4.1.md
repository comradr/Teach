# Планя 1.4.1 — исправление PDF/печати и RTF

Дата: 01.09.2026

## Исправлено

- `<br>`, `<br/>` и `<br />` больше не выводятся как буквальный текст при печати/PDF и в RTF.
- Переносы внутри ячеек не ломают Markdown-таблицу: HTML использует `<br>`, RTF — `\line`.
- `**жирный**`, `*курсив*`, `_курсив_` и inline code переводятся в формат целевого документа, а не остаются служебной разметкой.
- RTF-таблицы теперь содержат реальные строки/ячейки и явные границы каждой ячейки (`\trowd`, `\intbl`, `\cellx`, `\clbrdr*`, `\row`).
- Для заголовка RTF-таблицы добавлена заливка, для ячеек — внутренние отступы и вертикальное выравнивание.
- RTF настроен под A4 и полезную ширину страницы.
- Типовая пятиколоночная таблица урока использует пропорции 8% / 18% / 31% / 27% / 16%.
- PDF/печать использует настоящий HTML `<table>`, фиксированные пропорции колонок, повторяемый заголовок таблицы и защиту строк от разрыва между страницами.
- Добавлена обработка распространённых HTML entities без двойного декодирования.
- Добавлены регрессионные тесты специально на дефекты из реальных скриншотов.
