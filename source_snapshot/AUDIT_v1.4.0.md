# Аудит приложения «Планя» — версия 1.4.0

Дата: 31.08.2026

## Итог

«Планя» остаётся нативным Android-приложением на Kotlin, Jetpack Compose, Room и Gemini API. Переименование затрагивает пользовательский бренд и launcher label, но не меняет `applicationId` (`com.aistudio.lessonplanner.xyazqw`), поэтому версия 1.4.0 является обновлением версий 1.1.0–1.3.0 при одинаковой подписи.

Новая концепция лучше связывает продукт и персонажа: Планя — не декоративная картинка, а помощница учителя. В hero-блоке она проверяет тетради за столом; нажатие по иллюстрации по-прежнему открывает локальные настройки Gemini-ключа.

## Архитектурная карта

| Слой | Основные части | Состояние |
| --- | --- | --- |
| UI | Generator, Folders, Plans, Favorites, PlanDetail, общие компоненты и mascot states | Работает, но Generator и PlanDetail ещё крупные |
| State | LessonPlannerViewModel, PlannerFoldersViewModel, LessonPlanListViewModel, LessonTemplateViewModel | Бизнес-состояние не перенесено в composable |
| Данные | Room entities, DAO, repository, backup/restore | Реальные данные, без моков |
| AI | GeminiApiService, prompt builder, repair, validator, error mapper | Сохранены retry, IPv4 fallback и классификация ошибок |
| Android | Камера, галерея, голос, Share, календарь, Print Framework | Реализовано, требует проверки на телефоне |

## Что реализовано хорошо

- Режим одного класса и полноценный МКШ с раздельными материалами.
- Проверка точного таймлайна и ограничений самостоятельной работы.
- Repair результата Gemini вместо слепого принятия ответа.
- Сохранение, черновики, папки, архив, избранное, теги и клонирование.
- Перегенерация раздела с Undo.
- Пятиминутка, структура презентации и домашнее задание по фотографии.
- Карточки ученику, ответы учителю, таймер, RTF, Share, календарь и печать карточек.
- Пользовательские шаблоны в Room: создание, применение, редактирование, удаление и backup.
- Глобальный поиск планов по всей базе, а не только внутри открытой папки.
- Сортировка планов по дате, названию, предмету и классу.
- Счётчики планов на карточках папок.
- Backup и restore выполняются транзакционно; повторное восстановление не дублирует планы.
- RTF-экспорт преобразует Markdown-таблицы в настоящие таблицы документа.
- Отдельная печать/PDF всего плана с заголовками, списками и таблицами; печать карточек сохранена отдельно.
- Compile-проверки адаптивной Compose-компоновки для 320/360/393/412/600 dp и увеличенного текста.
- До пяти фотографий материалов на каждый класс: до десяти в МКШ, множественный выбор из галереи, прокручиваемые превью и сохранение порядка страниц в Gemini-запросе.
- Локальное шифрованное хранение Gemini-ключа; ключ не попадает в backup и логи.
- Стабильная подпись APK и сохранённый package id для последующих обновлений.

## Функции, которые реализованы недостаточно

| Приоритет | Функция | Что именно не хватает |
| --- | --- | --- |
| Высокий | Device regression | Камера, голос, VPN/Gemini, календарь, Share и печать не могут считаться полностью проверенными без телефона |
| Высокий | Экспорт PDF | PDF доступен через системный диалог печати; отдельной кнопки «сохранить PDF» без Android Print UI нет |
| Средний | Папки | Счётчик планов есть, но даты последнего изменения папки пока нет |
| Средний | Шаблоны | Нет быстрого дублирования и поиска; фотографии намеренно не входят в шаблон |
| Средний | План результата | Разделы распознаются эвристически по Markdown; нестандартный ответ Gemini может структурироваться хуже |
| Средний | Адаптивность | Основные настройки проверяются compile-тестами на 320–600 dp, но нет полноценного screenshot-набора всех экранов |
| Средний | Доступность | Не проведён отдельный проход TalkBack, контрастности и font scale 1.5–2.0 |
| Средний | Архитектура | GeneratorScreen и PlanDetailScreen всё ещё крупные; интеграционные действия смешаны с UI-кодом |
| Низкий | Диагностика | Нет безопасного экрана «О приложении» с версией и диагностикой без ключа/API-ответов |

## UX-наблюдения по присланным экранам

- Старое название «МКШ Планировщик» описывало функцию, но не создавало собственного характера.
- Маленький стоящий маскот выглядел наклейкой и оставлял правую часть hero-карточки пустой.
- Новая сцена с Планей за столом лучше объясняет роль помощницы и заполняет выделенную область.
- Кнопки «Шаблоны» и «Очистить» остаются отдельной строкой, поэтому не конфликтуют с иллюстрацией на узких экранах.
- Принудительная светлая тема оправдана: текущая палитра и часть иллюстраций ещё не имеют корректных dark-вариантов.
- Нижняя навигация читаема, но при увеличенном системном шрифте её всё равно нужно проверить на реальном устройстве.

## Проверяемая регрессия

Автоматически должны проходить:

- 66 unit-тестов;
- компиляция 7 Android Compose-тестов адаптивности;
- `lintDebug`;
- `assembleDebug`;
- проверка APK Signature Scheme v2/v3.

На физическом Android-устройстве нужно проверить:

1. Обновление 1.1.0–1.3.0 → 1.4.0 без удаления приложения и потери Room-данных.
2. Hero-блок на 320–412 dp и при увеличенном шрифте.
3. Нажатие на Планю и сохранение нового Gemini-ключа.
4. Обычную и МКШ-генерацию через реальную сеть/VPN.
5. До пяти изображений на каждый класс, множественный выбор из галереи и последовательную съёмку камерой.
6. Голосовой ввод и отказ в разрешении.
7. Share, календарь, RTF, печать всего плана и печать карточек через Android Print Framework.
8. Backup/restore после переустановки.
