# Отчёт по рефакторингу «МКШ Планировщик»

## Baseline

- Исходный ZIP сохранён отдельно и зафиксирован локальным baseline-коммитом.
- Исходная локальная проверка не дошла до компиляции: в рабочей среде отсутствовали Android SDK и Gradle 9.3.1, а сеть не позволяла скачать Gradle.
- Проверка в GitHub Actions выявила существующую несовместимость OkHttp Dns: lambda-конструктор не поддерживался подключённой версией OkHttp. IPv4 fallback переписан на эквивалентный object : Dns без изменения поведения.
- Сохранены распознавание User location is not supported for the API use и повтор через IPv4.

## Архитектура

- MainActivity.kt уменьшена примерно с 1750 строк до Activity-level инициализации.
- Навигация вынесена в navigation/PlannerApp.kt.
- Экраны разделены по каталогам ui/screens/generator, folders, plans, plan_detail.
- Общие карточки, кнопки, карточка плана, структурированный Markdown и маскот вынесены в ui/components.
- Созданы централизованные Color.kt, Shape.kt, Motion.kt; случайные параметры анимации не размазываются по новым компонентам.
- ViewModel, Room, DAO, repository, Gemini prompts, validator и persistent state не переносились в локальный UI-state.

## Визуальный дизайн

- Реализована светлая violet/rose kawaii-система без кислотных цветов.
- Переработаны генератор, папки, список планов, избранное, детали плана и нижняя навигация.
- Hero генератора стал компактным и адаптивным.
- Режим одного/двух классов, параметры плана и продолжительность оформлены компактно.
- Каждый класс имеет отдельную карточку и собственные материалы.
- Редкие параметры перенесены в раскрываемый блок.
- Результат разбивается на Markdown-секции; таблицы получают горизонтальную прокрутку.
- Действия готового плана используют адаптивный FlowRow, а не фиксированную строку кнопок.

## Маскот и motion

- Добавлена оригинальная незаимствованная кошечка-помощница.
- Состояния: Idle, Loading, Success, Error, Empty, Hint, а также отдельные контекстные позы для папок, избранного, списка планов и подсказки.
- Ассеты оптимизированы в WebP.
- Добавлены: press scale, появление второго класса, раскрытие настроек, смена generation state, favorite feedback, screen transitions и спокойная loading-анимация.
- Ложные проценты прогресса не используются.

## Полировка по проверке на устройстве

- Убраны грязные полупрозрачные заливки карточек классов: используются почти белые сплошные поверхности с разными чистыми оттенками и цветным маркером класса.
- Убрано тяжёлое elevation у базовых карточек; границы стали мягче, а вложенные поля визуально отделены от секции.
- Hero-композиция стала ниже; название помещается в одну строку на компактной ширине.
- Действия с фотографиями сокращены до «Галерея» и «Камера» и размещаются рядом на обычной ширине телефона.
- Подписи ограничений самостоятельной работы сокращены и дополнены отдельным суффиксом «мин».
- Empty-state папок помещён в компактную карточку; папки, избранное и планы больше не используют одну и ту же иллюстрацию.

## Gemini: диагностика и восстановление

- Подтверждён дефект: основной сценарий генерации обходил общий executor с retry и IPv4 fallback; этот механизм использовали только дополнительные AI-действия.
- Основная генерация, repair, перегенерация раздела, пятиминутка, презентация и ДЗ теперь используют единый безопасный путь запросов.
- Сохранён IPv4 fallback для `User location is not supported for the API use`.
- HTTP 429 разделяется на минутный rate limit, дневную квоту, отсутствие доступной квоты и лимит расходов; для короткого ограничения учитывается `Retry-After`/`retryDelay`.
- Дневная/нулевая квота больше не вызывает бессмысленные мгновенные повторы.
- Модель не изменялась: `gemini-3.5-flash` остаётся текущей стабильной моделью проекта.

## Сохранённые функции

Существующая реализация оставлена подключённой для:

- одного класса и МКШ;
- темы, типа, режима и длительности;
- ограничений самостоятельной работы;
- раздельных материалов классов, галереи и камеры;
- до пяти изображений на каждый класс с множественным выбором из галереи;
- голосового ввода;
- Gemini, retry/repair, валидатора и точного МКШ timeline;
- черновиков;
- Room, папок, архива, поиска, тегов и избранного;
- сохранения, редактирования, перегенерации раздела и Undo;
- пятиминутки, презентации и ДЗ по фото с выбором класса;
- таймера, Share, RTF, календаря, клонирования, backup/restore и Android Print Framework;
- Markdown, карточек ученику и ответов учителю.
